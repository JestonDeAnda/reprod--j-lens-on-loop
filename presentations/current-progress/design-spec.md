# J-Lens 完整复现：当前进展汇报 Slides 设计规格

## 项目与目标

这是一份面向研究负责人和熟悉大模型实验的协作者的阶段汇报。它不是项目介绍，
也不是论文科普，而是用于在 5–8 分钟内回答三个管理问题：完整复现目前到了哪里，
现有证据说明了什么，以及接下来需要做哪些决定。汇报必须严格区分“训练产物已经
存在”“分析程序已经运行”“结果已有初步信号”和“论文结论已经复现”四种状态。

## 真实内容与事实截点

事实截点为 2026-10-26 11:08 CST。Ouro full 已成功并具有 4/4 lens；Huginn primary
已有 4/4 lens；Huginn tiling 目前具有 13/16 lens；Nanbeige full 已成功并具有 2/2
lens。结构分析已在 DSW 完成，产出 6 个 JSON：Ouro 与 Huginn 各自的 distance、
symmetry 和 factorisation。Ouro 共有 27 个距离记录、39 个 symmetry 记录和 39 个
factorisation 记录；Huginn 分别有 25、16、16 个记录。所有 52 个距离记录的 operator
norm power iteration 均收敛。首批摘要只能称为信号：Ouro symmetry 的 relative
operator difference 中位数为 0.725，factorisation relative operator error 中位数为
0.210；Huginn 对应为 0.209 和 0.736。这个对照值得突出，但不能直接升级为论文结论。
Qwen3.6-27B 的 OSS 归档目前约 27GB，根目录仍只有 5 个完整 shard，续传正在进行；
Ouro-2.6B-Thinking 尚未开始，因为排在 Qwen 之后。语义传输仍待锁定 concept token、
unembedding 和 prompt 协议。当前代码最新提交为 f9191a5，本地 19 项测试通过。

## 正式 Deck 建议结构

正式版本预计 8–10 页：封面结论、全局进度、训练覆盖、当前运行状态、结构分析方法、
Ouro/Huginn 首批对照、权重归档、风险与未决、下一阶段安排、决策页。第一页应直接
给出“拟合主体基本完成，工作已进入结构分析；但 Huginn tiling、Qwen 权重和语义协议
仍未闭环”。数据页只显示能追溯到 JSON 或命令输出的数字。

## 输出与交互

最终交付为一个可双击打开的单文件 HTML，内部每页为独立 1920×1080 section。支持
左右方向键、空格翻页、Home/End、全屏以及窗口自适应缩放；页面索引由统一外壳生成，
单页不重复绘制页码。此次三方向初稿各做两页：封面/总览页和结构分析结果页，它们是
视觉差异最大的两个页面类型。正式版选择方向后才批量生成。

## 视觉与内容约束

这是研究型汇报，不使用 stock photo、品牌 logo 或装饰性插画。具名模型 ID 仅作为
实验对象和溯源文本，不作为品牌营销资产呈现。视觉母题来自 Jacobian 本身：层间传输、
循环边界、矩阵谱和尚未闭合的实验链路。正文不小于 28px，注释不小于 20px，确保会议
室投屏可读。禁止通用紫色渐变、emoji、整页同质圆角卡片、虚构 KPI、无来源数字和
“进展顺利”之类空洞表述。每页只承担一个主要判断，来源路径以短注脚形式保留。

## 三方向共同评价标准

三个方向使用完全相同的内容事实，但布局骨架必须不同。评价标准依次是：十秒内能否
抓住当前阶段；初步结果与风险是否被清楚区分；投屏可读性；能否扩展到 8–10 页而不
重复；单文件实现是否稳定。方向选定后可混合，例如采用 A 的封面力度、B 的图表规范
和 C 的结构图语言。
